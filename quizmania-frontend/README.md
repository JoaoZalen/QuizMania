# quizmania-frontend

Front-end em Vue do QuizMania. Consome a API do projeto `quizmania-backend-api` (porta 3000).

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Lints and fixes files
```
npm run lint
```
